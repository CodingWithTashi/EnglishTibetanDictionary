# App icon generator

Generates the launcher icon, the splash icon and the legacy PNG icons from one geometry: the open
bilingual book on the red tile, with "བོད" and "En" on its pages. Every file in the table below is
generated; the drawables say so in a "Generated by tools/icon/gen.py: do not hand-edit" comment.
To change the icon, change `gen.py` and run both scripts again.

There are two variants. The Tibetan one is the default. The Dzongkha one puts "རྫོང" on the left page
instead of "བོད"; Bhutan SIMs (mcc402) get it as the launcher and splash icon, and the installing screen
shows it while the Dzongkha dictionary is prepared. The background and monochrome layers have no text,
so both variants share them.

| Script | Writes |
|---|---|
| `gen.py` | `drawable/ic_launcher_background.xml`, `drawable/ic_launcher_foreground.xml`, `drawable/ic_launcher_monochrome.xml`, `mipmap-anydpi-v26/ic_launcher.xml`, `mipmap-anydpi-v26/ic_launcher_round.xml`, `drawable/ic_splash_tile.xml`, `drawable/ic_splash_icon.xml`, `drawable-v26/ic_splash_icon.xml`; for Dzongkha, `drawable/ic_splash_tile_dz.xml`, `drawable-mcc402/ic_launcher_foreground.xml`, `mipmap-mcc402-anydpi-v26/ic_launcher.xml`, `mipmap-mcc402-anydpi-v26/ic_launcher_round.xml`, `drawable-mcc402/ic_splash_icon.xml`, `drawable-mcc402-v26/ic_splash_icon.xml` |
| `render.py` | `mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` and `ic_launcher_round.png` (API 24 and 25) and the same in `mipmap-mcc402-*` for Dzongkha, plus preview images in `previews/` |
| `relpen.py` | Nothing; `gen.py` uses it to write compact path data |

- `ic_launcher_*` are the adaptive icon layers (108dp canvas, the tile fills the 72dp visible area).
  The monochrome layer is the themed-icon silhouette.
- `mipmap-mcc402-anydpi-v26/` repeats the adaptive icon: the country qualifier outranks density and version,
  so without it the `mipmap-mcc402-*` PNGs would replace the adaptive icon on Bhutan SIMs at every API level.
- `ic_splash_tile` is the icon at 84dp with its drop shadow, in a 136dp frame. The installing screen
  draws it as it is.
- `ic_splash_icon` puts that tile in the 288dp frame the splash screen draws its icon in. `drawable/`
  uses dp insets (API 24 and 25); `drawable-v26/` uses fractions, which still hold when the
  API 31+ splash draws the icon at another size.

## Fonts

`gen.py` reads two fonts from `app/src/main/res/font`:

- `jomolhari_regular.ttf` for "བོད" (30 units, centred on x 54, baseline 92 of the 160-unit tile) and
  "རྫོང" (30 units, centred on x 54, baseline 95: its stacked letter hangs lower)
- `noto_sans_semibold.ttf` for "En" (26 units, centred on x 106, baseline 90)

The text is shaped with HarfBuzz and outlined with fontTools, so the drawables contain paths, not text.
A change to either font file changes the icon.

## Setup

Python 3.13 (the committed files were made with 3.13.7):

```sh
cd tools/icon
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

`requirements.txt` pins the versions that reproduce the committed files byte for byte.
`.venv/` is git-ignored.

## Regenerate

Run `gen.py` first, because `render.py` draws the PNGs from the XML that `gen.py` writes:

```sh
cd tools/icon
.venv/bin/python -I gen.py      # vector drawables
.venv/bin/python -I render.py   # legacy PNGs and previews
```

Both default to `../../app/src/main/res`; pass another `res` directory as the first argument to write
somewhere else (and, for `gen.py`, a font directory as the second). With unchanged inputs both scripts
rewrite the same bytes, so `git status` shows no change.

`render.py` also prints a glyph check for each variant: it compares the rounded glyph paths in the foreground
with the exact outlines (from `glyph_reference.json`, which `gen.py` writes per drawable folder) at 16 times
the tile size. Only edge pixels should differ.

The preview images (adaptive icon in a circle and a squircle, safe zone, monochrome, splash on the light
and dark backgrounds, installing tile; the Dzongkha ones have `mcc402` or `dz` in the name) go to `previews/`. They and `glyph_reference.json` are git-ignored;
do not commit them.

## Artwork override (Tibetan launcher and splash)

The default (Tibetan) launcher and splash icon now come from `artwork/app-icon-512.png`, not from `gen.py`:
`mipmap-anydpi-v26/ic_launcher*.xml`, `drawable/ic_launcher_art_*.xml`, `drawable-nodpi/ic_launcher_art*.png`,
`drawable-nodpi/ic_splash_art.png`, `drawable{,-v26}/ic_splash_icon.xml` and the `mipmap-{m,h,xh,xxh,xxxh}dpi`
PNGs. Re-running `gen.py` or `render.py` overwrites them with the old book icon. The Dzongkha (mcc402)
variant and the installing-screen tiles are unchanged.
